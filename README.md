# face-recognition-claptrap

A computer vision project that involves building a facial recognition pipeline from scratch. It's part of a much larger project to build an AI agent with the personality of Claptrap from Borderlands, while including dynamic pan-tilt tracking and voice interaction. 

## Current Features 
-Live camera feed using OpenCV\
-Real-time face detection using MediaPipe\
-Bounding boxes around detected Faces\
-Video recording to file\
-Facial Landmark Detection\
-Face Embedding generation using Facenet(InceptionResnetV1)\
-Face matching and Identity Recognition\
-Face enrollment system (use 'a' to enroll)\
-Face database saved to file\
-Delete enrolled faces from database(use 'd' to delete)
