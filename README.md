# face-recognition-claptrap

A computer vision project that involves building a facial recognition pipeline from scratch. It's part of a much larger project to build an AI agent with the personality of Claptrap from Borderlands, while including dynamic pan-tilt tracking and generative voice interaction. 

## Current Features 
-Live camera feed using OpenCV\
-Real-time face detection using MediaPipe\
-Bounding boxes around detected Faces\
-Video recording to file\
-Facial Landmark Detection

## Roadmap
-Face embedding pipeline built from scratch\
-Face matching and identity recognition\
-Pan-tilt servo motor control\
-Claptrap AI personality layer
